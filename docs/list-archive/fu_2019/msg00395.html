Thanks to the message from Tony, and his checking my changes, there is a simple solution to this problem that also gets rid of the warning messages produced in earlier Mac OS X versions.
I will work on getting an update out in conda that includes this change, but for those comfortable "tweaking" Python scripts, the change is to add

try:
    import multiprocessing
    multiprocessing.set_start_method('spawn')
except:
    pass

somewhere near the beginning of $FER_DIR/lib/python3.7/site-packages/pyferret/__init__.py
This initialization of the multiprocessing package tells it to use "spawn" instead of "fork" to create new processes.
