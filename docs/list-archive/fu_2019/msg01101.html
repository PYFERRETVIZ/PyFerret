Yes, it is possible to install multiple versions, each in its own environment.
Some of us Mac users did this to install v7.5, to avoid the image-clipping that occurred in v7.63.

See messages around 25 Oct 2021 with subject "Solving the Mac/FRAME problem for PyFerret: use 7.5".

In this message string, see detailed, step-by-step instructions to do this. It's really pretty easy.
