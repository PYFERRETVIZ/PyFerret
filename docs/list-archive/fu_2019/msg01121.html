Hi Patrick

For the larger file, Ferret is breaking up the calculation along the T axis, using the split/gather capability described here,
../../documentation/users-guide/computing-environment/MEMORY-USE

You can see this in action if you wish, with the setting "SET MODE DIAGNOSTIC" before running the script.

For the smaller file, it is not doing that but instead always reports that the grid is too big. I don't know why this is. I tried setting the memory to smaller and larger values to see if I could force it to do the splitting but without success. I think this must be a bug, and I'll write up a report.

Ansley
