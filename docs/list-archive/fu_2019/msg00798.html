Hi to all.

In ferret, you can can construct a variable variable from scratch with something like A=I[I=1:5]  :

yes? LIST I[I=1:5]
             VARIABLE : I
                        axis ABSTRACT
             SUBSET   : 5 points (X)
 1   / 1:  1.000
 2   / 2:  2.000
 3   / 3:  3.000
 4   / 4:  4.000
 5   / 5:  5.000

You can limit the range :

yes? LIST I[I=3:5]
             VARIABLE : I
                        axis ABSTRACT
             SUBSET   : 3 points (X)
 3   / 3:  3.000
 4   / 4:  4.000
