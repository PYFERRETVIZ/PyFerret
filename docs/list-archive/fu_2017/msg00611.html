Hi Roger,
You can ask Ferret to use one extra grid-cell around the globe as it's drawing the plot. Using a dataset from the Ferret distribution,
yes? use monthly_navy_winds
yes? let clim = uwnd[t=1-jan-1989:31-dec-2008@ave]
yes? go mp_orthographic 90 -45
yes? set grid clim
yes? go mp_aspect
yes? LET masked_clim = clim * mp_mask

! Here is the gap you're seeing. The plot doesn't interpolate out to the edges of the cells at the
! ends of the x axis.

yes? FILL/NOAX/NOLAB masked_clim, x_page, y_page

! The curvilinear plot commands take into account a SET REGION setting,
! and because the grid is modulo in X, any setting with a range of 360 degrees
! will draw the plot you want:

yes? set region/x=0:360
yes? FILL/NOAX/NOLAB masked_clim, x_page, y_page
Ansley

go mp_grid clim
go mp_aspect

go mp_land.jnl

Second plot:
use "/Users/bodmanr/Desktop/Working_Suites/u-aj458/tas_aj458.nc"
let clim = tas[t=1-jan-1989:31-dec-2008@ave] -273
go mp_orthographic 90 -45
set grid clim
go mp_aspect
LET masked_clim = clim * mp_mask
FILL/NOAX/NOLAB masked_clim, x_page, y_page
go mp_land
