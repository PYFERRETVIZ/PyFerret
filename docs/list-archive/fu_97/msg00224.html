This is in regards to my letter yesterday dealing with the animation
example on page 83 of the Ferret User's Guide.  When running that
example as a script, the "repeat" command was not executing, yet the
rest of the script ran fine w/o error.  Steve Hankin suggested that this
was due to the lack of a carriage return after the repeat command.  It
turns out this was the problem.  If you don't hit return after the last
line in your editor, it appears that that line will not be executed.
