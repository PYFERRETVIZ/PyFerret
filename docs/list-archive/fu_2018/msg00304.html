Hi Sandeep,

As I mentioned in my last email, I did it in a multi-approach and straight-forward way, which is simply saving the correlations over the 20-year window.

Initially, save the sliced-window (here 20-year) of the data in separate files, eg:

repeat/range=1:28/name=ii (set region/l=`ii`:`ii+19`; save/file=data1_`ii`.nc/append $data1)

repeat/range=1:28/name=ii (set region/l=`ii`:`ii+19`; save/file=data2_`ii`.nc/append $data2)
